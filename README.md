# FrameModeler-Web

**Ver.1.0.0**

建築構造フレームモデリング CAD ツールの Web アプリケーション版です。ブラウザ上で節点・梁・柱・床・壁・耐力壁を配置・編集し、3D で確認できます。

## 機能

- 節点 (Node)、梁 (Beam)、柱 (Pillar)、床 (Floor)、壁 (Wall)、耐力壁 (BearWall) の配置・編集
- 2D 平面図 / 3D パース表示と、表示形状に対応した 2D screen-space / 3D Raycaster 選択
- レイヤー（階）の追加・削除・選択と、一覧のダブルクリックによる名前・高さ編集
- グリッドと、既存節点・端点・中点・部材交点・グリッドへのオブジェクトスナップ
- X / Y / Z 座標の数値入力と、節点・梁・柱・床・壁・耐力壁の選択フィルタ
- JSON schema version 1 での保存・読込（version なしの従来 JSON も読込可能）
- 構造解析用 YAML からの CAD 形状変換と、元 ID・材料・断面・警告などの provenance 永続化
- Undo / Redo、未保存状態表示、破壊操作前の確認、IndexedDB draft 復旧
- 保存前モデル検証と、エラー・警告対象の選択
- Pointer Events によるパン・ズーム・回転とレスポンシブな canvas resize
- 日本語 / English、ダーク / ライトテーマ、キーボード操作、アクセシブルなダイアログ
- アプリ内操作マニュアル

## セットアップ

Node.js `^20.19.0` または `>=22.13.0` が必要です。

```bash
npm install
npm run dev              # 開発サーバー
npm run build            # 型検査 + 本番ビルド
npm run preview          # ビルド結果プレビュー
```

品質確認用のスクリプトも用意しています。

```bash
npm run typecheck        # アプリの型検査
npm run typecheck:test   # テストコードを含む型検査
npm run lint             # ESLint
npm run format:check     # Prettier差分確認
npm test                 # 単体・DOMテスト
npm run test:coverage    # カバレッジ出力
npm run check            # typecheck / test typecheck / lint / test / build
```

Pull Request と `main` への push では CI が型検査、lint、テスト、ビルド、high 以上の依存監査を実行します。GitHub Pages の deploy も同じ品質ゲートを通過した成果物だけを公開します。

## 操作方法

### ツール

| ツール     | 操作                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------- |
| 選択       | クリックで要素選択（Shift: 追加, Ctrl: 反転）、ドラッグで矩形選択、ダブルクリックでプロパティ表示 |
| 移動       | 選択した節点をクリックして移動。確定前に Esc またはツール切替すると元の位置へ戻る                 |
| 節点追加   | クリック位置に節点を追加                                                                          |
| 梁追加     | 2 点をクリックして梁を追加                                                                        |
| 柱追加     | クリック位置に柱を追加（現レイヤーから直上要素まで）                                              |
| 床追加     | 2 点クリックで矩形の床を追加                                                                      |
| 壁追加     | 2 点クリックで壁を追加                                                                            |
| 耐力壁追加 | 2 点クリックで耐力壁を追加                                                                        |

2 点作図の 1 点目は preview として保持され、2 点目の確定時に必要な節点と要素をまとめて追加します。新規作成、読込、削除、レイヤー切替、2D/3D 切替、Esc、ツール切替では途中操作をキャンセルします。

### スナップ

スナップが有効なときは、現在の作業平面上にある候補を CSS pixel 距離で判定し、次の優先順で利用します。

1. 既存節点・部材端点
2. 部材中点
3. 同一作業平面上の部材交点
4. グリッド

`Alt` を押している間はオブジェクトスナップとグリッドスナップを一時的に無効化できます。節点・端点・中点・交点へスナップしたときは canvas 上に marker を表示し、ステータスバーへスナップ種別を表示します。

ツールバーの X / Y / Z に有限な座標値を入力して `入力` を押すか Enter を押すと、現在の作図ツールへクリック位置として渡せます。2 点作図では、同じ入力欄を使って 1 点目と 2 点目を順番に確定できます。

### カメラ操作

| 操作          | 動作                |
| ------------- | ------------------- |
| 右ドラッグ    | 2D: パン / 3D: 回転 |
| 中央ドラッグ  | パン                |
| ホイール      | ズーム              |
| Home または F | モデル全体を表示    |

### ツールバーとレイヤー

| 操作                     | 機能                                           |
| ------------------------ | ---------------------------------------------- |
| 元に戻す / やり直す      | モデル編集履歴の Undo / Redo                   |
| 検証                     | モデル不変条件のエラーと作図上の警告を一覧表示 |
| 読込情報                 | YAML 読込時の元 ID、警告、材料、断面などを表示 |
| X / Y / Z + 入力         | 現在の作図ツールへ数値座標を渡す               |
| 選択対象                 | すべて、節点、梁、柱、床、壁、耐力壁から選択   |
| レイヤーをダブルクリック | レイヤー名と高さを編集                         |
| レイヤー一覧の ↑ / ↓     | キーボードで前後のレイヤーへ移動               |
| EN / JA                  | 表示言語の切替（日本語 ⇔ English）             |
| ☾ / ☀                    | ダークモード / ライトモード切替                |
| ?                        | 操作マニュアルの表示                           |

レイヤー高さは重複できません。レイヤー削除時には、その高さに関連する要素数を確認してから削除します。言語とテーマの設定はブラウザに保存され、次回アクセス時にも維持されます。

| Ctrl + Y または Ctrl/Cmd + Shift + Z | やり直す             |
| Ctrl/Cmd + S                         | 保存                 |
| Ctrl/Cmd + O                         | 開く                 |
| Esc                                  | 途中操作をキャンセル |

## Undo / Redo、未保存状態、draft 復旧

- モデル、プロパティ、レイヤー、追加・移動・削除をスナップショット履歴として管理します。
- 選択状態だけの変更は編集履歴や未保存判定に含めません。
- 保存済み状態との差があると、ブラウザタイトルとステータスのバージョン表示に `*` が付きます。
- 未保存状態で New / Open / ブラウザ終了を行う場合は確認します。
- 未保存モデルは一定時間後に IndexedDB へ draft 保存され、次回起動時に復旧候補を提示します。
- IndexedDB が利用できない環境でも、draft 機能だけを無効にして通常操作を継続します。

## モデル検証

`検証` ボタン、JSON/YAML 読込、Document 更新、保存で共通の検証規則を使用します。保存を止めるエラーに加え、確認が必要な項目は警告として表示します。対象付きの項目はダイアログから該当要素を選択できます。

- 非有限値、不正 ID、重複 ID、Document 外参照
- 零長部材、退化・非平面・自己交差する面、壁・耐力壁の頂点数
- レイヤー高さの重複
- 孤立節点、重複座標節点、重複部材
- 未設定 section、レイヤー外節点、異なる高さを結ぶ梁
- YAML provenance の stale 参照

## データ形式

保存形式は JSON schema version 1 です。`schemaVersion` がない従来形式は legacy v0 として検証・移行して読み込みます。未対応の schema version、不正な型、非有限値、重複 ID、欠落参照、退化形状は既存 Document を置換する前に拒否します。

```json
{
  "schemaVersion": 1,
  "nodes": [
    { "number": 0, "pos": { "x": 0, "y": 0, "z": 0 } },
    { "number": 1, "pos": { "x": 6000, "y": 0, "z": 0 } }
  ],
  "beams": [{ "number": 0, "nodeI": 0, "nodeJ": 1, "section": "G1" }],
  "pillars": [],
  "floors": [],
  "walls": [],
  "bearWalls": [],
  "layers": [{ "name": "1F", "posZ": 0 }]
}
```

`select` などの一時 UI 状態は v1 のモデル JSON には保存しません。YAML から読み込んだモデルでは、次の情報を optional な `importMetadata` として同じ JSON に保存します。

- 読込形式・モード・モデル名・単位・警告・件数
- 元節点 ID / 元部材 ID と現在の Node / Member / Plane 番号の対応
- 元要素型、section、material、要素 tag、元節点 ID、変換注記
- 材料特性と断面特性

`importMetadata` 内の参照は `category + number` で保持し、モデル件数・参照・summary の整合性を読込前と保存前に検証します。

### 座標系

- X 軸: 右方向
- Y 軸: 奥行き方向
- Z 軸: 高さ方向（上）
- 単位: mm

### 構造解析用 YAML の読込

`schema_version`, `units`, `model`, `traceability` を持つ構造解析用 YAML を読み込み、CAD 表示用の節点・梁・床・レイヤーへ変換できます。

- 対応拡張子: `.yaml`, `.yml`
- 読み込み後の保存形式: schema version 1 の JSON
- 変換方針: 読込時に「元 CAD 形状」または「生成済み解析要素」を選択
  - 元 CAD 形状: `traceability` を優先し、解析メッシュではなく元 CAD 形状に近い形で復元
  - 生成済み解析要素: `model.nodes` / `model.elements` を節点・線材として表示
- JSON に永続化する情報: 元 ID 対応、section、material、材料特性、断面特性、変換警告・注記
- 未対応情報: 支点、節点質量、拘束、解析結果抽出設定

未対応情報は読込情報ダイアログの警告として表示されます。生成済み解析要素モードでは `elasticTimoshenkoBeam3D`, `truss3D`, `twoNodeLink3D` を表示用の梁として読み込み、元要素型を provenance に保持します。零長の `twoNodeLink3D` は専用 Spring 型がまだないため拒否します。これらを専用の解析要素として編集する機能や、支点・質量・拘束の表示・編集は今後の拡張です。

## アクセシビリティ

- toolbar/group、canvas、layer listbox、dialog の role と accessible name を設定しています。
- ダイアログは label と control を関連付け、初期 focus、Tab trap、Enter 確定、Esc、focus 復帰、inline 数値エラーに対応します。
- 言語切替時は表示テキスト、ARIA label、`<html lang>` を同期します。
- `:focus-visible`、高コントラスト、狭幅表示、coarse pointer 向け 44px 操作対象を用意しています。
